Architectural principles

One data model

Observation, planning, communication and analytics share one model; no duplicated data between modules.

Roles & permissions

Parent / teacher / leader work with distinct permission sets, enforced at the API level.

Scalability

The same architecture from a single site to multi-campus groups; multilingual by design.

Portability

School data is exportable; no lock-in by obscurity.
